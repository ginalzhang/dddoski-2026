# Custom link sources (optional)

Loaded at server start in addition to `seed/*.json`. Paths can be overridden with env vars.

| File | Env override |
|---|---|
| `data/fun-links.json` | `FUN_LINKS_PATH` |
| `data/edu-links.json` | `EDU_LINKS_PATH` |
| `data/transcripts.json` | `TRANSCRIPTS_PATH` |

## Link files (lenient)
An array (or `{ "links": [...] }`) whose items may be any of:
- a full `SeedLink` object (see `lib/types.ts`);
- a plain string: a YouTube URL (`watch?v=`, `/shorts/`, `youtu.be/`, `/embed/`) or an 11-char ID;
- a loose object with any of `url | link | video_id | videoId | id`, and optional `title`, `topic`,
  `question`, `options`, `correct_index | correctIndex | answer` (index, or the text of the right option), `explanation`.

Links with a duplicate (kind, video id) update the earlier entry.
- **Fun** links without a valid quiz stay active. A quiz comes from generated mode (`generateFunQuiz`) if
  available; otherwise the Short is auto-passed (no gate) for that session.
- **Edu** links without a valid quiz (question, 2-4 distinct options, in-range correct index, explanation)
  are loaded as `active=false`: they cannot gate Study Hall.

## Transcripts (lenient)
- `{ "<videoId>": "text" }`
- `{ "<videoId>": { "text" | "transcript": "...", "lang"?: "en", "isAutoGenerated"?: true } }`
- `[ { "videoId" | "video_id" | "id" | "url": "...", "transcript" | "text": "..." | [{ "text": "..." }] } ]`

Stored in the `videos` table; available via `getCachedTranscript(videoId)` from `lib/server/store`.
